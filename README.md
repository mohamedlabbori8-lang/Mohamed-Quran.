# Mohamed.Quran.com

موقع قرآن كريم بتصميم أخضر وذهبي، يدعم قراءة السور والاستماع إلى التلاوات.

## الملفات
- `index.html`: هيكل الموقع.
- `style.css`: الألوان والتصميم.
- `script.js`: تحميل السور وتشغيل التلاوة.

## التشغيل
افتح `index.html` في متصفح حديث مع اتصال بالإنترنت.

يعتمد الموقع على:
- AlQuran Cloud API لبيانات السور والآيات.
- Islamic Network CDN لملفات التلاوة الصوتية.
